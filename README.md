# Umbra

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![CI](https://github.com/rajveersinh-is-dev/umbra/actions/workflows/ci.yml/badge.svg)](https://github.com/rajveersinh-is-dev/umbra/actions)


Research-grade Python library for MNAR-aware missing data diagnostics, identifiability bounds, and robust imputation under non-random missingness.

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/umbra.git
cd umbra
python "benchmarks/__init__.py" --help
```

## Testing

```bash
pytest tests/
```
