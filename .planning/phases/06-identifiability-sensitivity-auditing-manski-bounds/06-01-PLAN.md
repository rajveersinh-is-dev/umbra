# Plan 06-01: Manski Partial Identifiability Bounds Engine

**Goal:** Implement `compute_manski_bounds`, `compute_manski_quantile_bounds`, and `ManskiBoundsResult` in `umbra/diagnostics/manski_bounds.py` providing sharp nonparametric bounds on population mean and quantiles under zero untestable assumptions (Manski 1989, 2003).
**Requirements:** `IDENT-01`

## Tasks

1. **Create `umbra/diagnostics/manski_bounds.py`**:
   - Dataclass `ManskiBoundsResult`:
     - `feature: str`
     - `n_total: int`
     - `n_observed: int`
     - `n_missing: int`
     - `missing_rate: float`
     - `observed_mean: float`
     - `observed_std: float`
     - `support_lower: float`
     - `support_upper: float`
     - `mean_lower_bound: float`
     - `mean_upper_bound: float`
     - `mean_interval_width: float`
     - `median_lower_bound: float`
     - `median_upper_bound: float`
     - `quantile_bounds: Dict[float, Tuple[float, float]]`
     - Methods: `contains(value: float) -> bool`, `to_dict()`, `summary()`.
   - Function `compute_manski_bounds(y, support=None, quantiles=(0.25, 0.5, 0.75), trim_quantile=None) -> ManskiBoundsResult`:
     - Calculate $p_{\text{miss}} = \frac{N_{\text{miss}}}{N}$.
     - Resolve support $[y_L, y_U]$: from user parameter, or empirical $[\min(y_{\text{obs}}), \max(y_{\text{obs}})]$, or quantile trimming $[q_\epsilon, q_{1-\epsilon}]$.
     - Compute sharp mean bounds:
       $\text{LB} = \bar{Y}_{\text{obs}}(1 - p_{\text{miss}}) + y_L p_{\text{miss}}$
       $\text{UB} = \bar{Y}_{\text{obs}}(1 - p_{\text{miss}}) + y_U p_{\text{miss}}$
     - Compute sharp quantile bounds for each requested $\alpha \in (0, 1)$.
   - Function `compute_dataframe_manski_bounds(df, supports=None, quantiles=(0.25, 0.5, 0.75)) -> Dict[str, ManskiBoundsResult]`.
2. **Re-export**:
   - Re-export in `umbra/diagnostics/__init__.py` and top-level `umbra`.
3. **Verify**:
   - Verify interval width invariant $\Delta = p_{\text{miss}}(y_U - y_L)$ and test against synthetic and observational datasets.
