# Plan 04-01: Cost-Sensitive Decision Engine & Decision Profiles

**Goal:** Implement cost-sensitive decision engine (`RouterDecisionProfile`, `compute_bayes_optimal_threshold`, asymmetric loss matrix handling) and integrate into `assess_mnar_risk` and `diagnose_dataframe`.
**Requirements:** `ROUT-01`, `ROUT-03`

## Tasks

1. **Create `umbra/diagnostics/risk_calibrator.py`**:
   - Implement `compute_bayes_optimal_threshold(c_fn: float = 1.0, c_fa: float = 1.0) -> float`:
     $$\tau^* = \frac{C_{\text{FA}}}{C_{\text{FA}} + C_{\text{FN}}}$$
   - Implement `compute_expected_losses(p_mnar: float, c_fn: float = 1.0, c_fa: float = 1.0) -> Dict[str, float]`:
     returns `{"loss_mar": p_mnar * c_fn, "loss_mnar": (1 - p_mnar) * c_fa}`.
   - Implement `RouterDecisionProfile` dataclass:
     - `name: str`
     - `c_fn: float`
     - `c_fa: float`
     - `high_risk_threshold: float`
     - `medium_risk_threshold: float`
     - `tail_risk_threshold: float = 0.25`
     - `description: str = ""`
     - `to_dict() -> Dict[str, Any]`
     - `@classmethod from_dict(d) -> RouterDecisionProfile`
     - `save(path: str)` / `@classmethod load(path: str)`
   - Define built-in registry `ROUTER_PROFILES`:
     - `"balanced"`: $C_{\text{FN}} = 1.0, C_{\text{FA}} = 1.0, \tau_{\text{high}} = 0.50, \tau_{\text{med}} = 0.25$
     - `"conservative_mnar"`: $C_{\text{FN}} = 4.0, C_{\text{FA}} = 1.0, \tau_{\text{high}} = 0.20, \tau_{\text{med}} = 0.10$
     - `"permissive_mar"`: $C_{\text{FN}} = 1.0, C_{\text{FA}} = 4.0, \tau_{\text{high}} = 0.80, \tau_{\text{med}} = 0.40$
   - Implement helper `get_decision_profile(profile_or_name, loss_matrix=None) -> RouterDecisionProfile`.

2. **Update `umbra/diagnostics/mnar_risk_score.py`**:
   - In `MNARRiskReport`:
     - Add attributes: `calibrated_p_mnar: Optional[float] = None`, `decision_profile: Optional[str] = None`, `expected_loss: Optional[float] = None`, `loss_matrix: Optional[Dict[str, float]] = None`.
     - Update `to_dict()` and `summary()` to include these fields when present.
   - In `assess_mnar_risk`:
     - Accept `decision_profile: Optional[Union[str, RouterDecisionProfile]] = None`
     - Accept `loss_matrix: Optional[Dict[str, float]] = None`
     - If provided, dynamically resolve thresholds $\tau_{\text{high}}, \tau_{\text{med}}$ and compute expected loss.
   - In `diagnose_dataframe`:
     - Pass through `decision_profile` and `loss_matrix`.

3. **Verification**:
   - Run unit checks ensuring existing behavior is preserved when no profile is passed, and dynamic thresholds take effect when custom profile or loss matrix is passed.
