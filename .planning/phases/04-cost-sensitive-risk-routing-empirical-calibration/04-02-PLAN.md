# Plan 04-02: Empirical Probability Calibration & UmbraImputer Integration

**Goal:** Implement `MNARRiskCalibrator` with Platt scaling, Isotonic regression, and pre-fitted defaults; integrate calibration and decision profiles into `UmbraImputer`; author `tests/test_router_calibration.py`.
**Requirements:** `ROUT-01`, `ROUT-02`, `ROUT-03`

## Tasks

1. **Extend `umbra/diagnostics/risk_calibrator.py` with `MNARRiskCalibrator`**:
   - Class `MNARRiskCalibrator`:
     - Parameters: `method: str = "platt"`, `alpha: float = 1.0` (regularization).
     - `fit(scores: np.ndarray, y_true: np.ndarray) -> MNARRiskCalibrator`:
       - `"platt"`: Fits regularized logistic regression $P = \frac{1}{1 + \exp(-(w \cdot s + b))}$ ensuring $w > 0$.
       - `"isotonic"`: Fits `sklearn.isotonic.IsotonicRegression(y_min=0.0, y_max=1.0, out_of_bounds="clip")`.
       - `"linear"`: Fits min-max scaling with clipping.
     - `predict_proba(scores: Union[float, np.ndarray]) -> np.ndarray`:
       - Returns calibrated probabilities $\in [0.0, 1.0]$.
     - `calibrate(score: float) -> float`: Single-value scalar convenience.
     - Metrics:
       - `brier_score(scores: np.ndarray, y_true: np.ndarray) -> float`
       - `expected_calibration_error(scores: np.ndarray, y_true: np.ndarray, n_bins: int = 10) -> float`
     - Serialization:
       - `to_dict() -> Dict[str, Any]`
       - `@classmethod from_dict(d: Dict[str, Any]) -> MNARRiskCalibrator`
       - `save(filepath: Union[str, Path])`
       - `@classmethod load(filepath: Union[str, Path]) -> MNARRiskCalibrator`
     - Pre-trained default calibrator:
       - Provide built-in pre-calibrated default coefficients ($w_0, b_0$) based on the standard benchmark battery so any uncalibrated composite score can immediately be mapped to a sensible default $P(\text{MNAR})$.

2. **Integrate into `UmbraImputer` in `umbra/api.py`**:

   - In `fit(X, y=None)`:
     - Pass `decision_profile`, `loss_matrix`, and `calibrator` to `diagnose_dataframe()`.
     - Record `self.calibrated_p_mnar_: Dict[str, float] = {}`

     - Route columns using profile's `high_risk_threshold` and `medium_risk_threshold`.
   - Update `strategy_map_` and sklearn inspection properties.

3. **Public Re-exports**:
