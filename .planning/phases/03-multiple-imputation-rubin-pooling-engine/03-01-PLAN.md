# Plan 03-01: Multi-Draw Stochastic Imputation Interface

## Goal
Implement a consistent `transform_multiple(X, m=5, random_state=None) -> List[pd.DataFrame]` and `fit_transform_multiple(X, m=5, random_state=None) -> List[pd.DataFrame]` interface across all stochastic imputers in Umbra (`MARChainedEquationsImputer`, `HeckmanSelectionImputer`, `PatternMixtureImputer`, `DeepGenerativeMNARImputer`).
