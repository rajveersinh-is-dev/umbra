# Plan 02-01: Ridge Sandwich Covariance and Collinearity Diagnostics

## Goal
Implement regularized Ridge sandwich covariance matrix estimation ($V_{\text{ridge}} = \hat{\sigma}^2 Q_\alpha M Q_\alpha$) for ill-conditioned Heckman second stages, replacing NaN standard errors when Ridge fallback occurs (`HECK-03`), and implement VIF / condition index collinearity diagnostics for $[X_* \quad \lambda_1]$ (`HECK-04`).
