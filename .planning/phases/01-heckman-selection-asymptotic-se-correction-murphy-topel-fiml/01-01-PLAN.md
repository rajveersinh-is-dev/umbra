# Plan 01-01: Murphy-Topel Asymptotic Covariance Correction for Heckman Two-Step

## Goal
Implement the exact analytical Murphy & Topel (1985) two-step asymptotic covariance matrix correction in `HeckmanSelectionImputer`, retiring uncorrected naive OLS standard errors when `n_bootstrap_se == 0` and resolving Limitation #2 from `docs/limitations.md`.

  <acceptance_criteria>
    - `HeckmanSelectionImputer` contains private method `_compute_murphy_topel_covariance(self, X_star: np.ndarray, W_obs: np.ndarray, y_obs: np.ndarray, beta_star: np.ndarray, V1: np.ndarray, delta: np.ndarray) -> np.ndarray`
    - In `fit()`, when second-stage estimation succeeds without Ridge fallback and `n_bootstrap_se == 0`, `self.coef_stderr_` is computed from the square root of `np.diag(V2)[:-1]` (and `self.mills_stderr_` from `np.sqrt(V2[-1, -1])`)
    - `self.coef_cov_` stores the full $(k+1) \times (k+1)$ Murphy-Topel asymptotic covariance matrix
    - `self.sigma_` is adjusted per Heckman (1979) / Murphy-Topel (1985) formula: $\hat{\sigma}^2 = \frac{1}{n_1} \sum \hat{\nu}_i^2 + \hat{\beta}_\lambda^2 \bar{\delta}$
    - `self.rho_` is estimated as $\hat{\rho} = \hat{\beta}_\lambda / \hat{\sigma}$ clipped to $[-0.999, 0.999]$
  </acceptance_criteria>
  <action>
    Modify `umbra/imputers/heckman_selection.py`:
    1. In `_fit_second_stage_ols`, calculate selection hazard curvature $\delta_i = \lambda_i (\lambda_i + w_i \hat{\gamma})$ for each observed unit $i$.
    2. Compute adjusted disturbance variance $\hat{\sigma}^2 = \frac{1}{n_1} \sum_{i=1}^{n_1} \hat{\nu}_i^2 + \hat{\beta}_\lambda^2 \bar{\delta}$, where $\bar{\delta} = \frac{1}{n_1}\sum \delta_i$.
    3. Compute $\hat{\rho} = \text{clip}(\hat{\beta}_\lambda / \hat{\sigma}, -0.999, 0.999)$.
    4. Implement Murphy-Topel covariance matrix:
       $$V_2 = \hat{\sigma}^2 (X_*^T X_*)^{-1} \left[ X_*^T (I - \hat{\rho}^2 \Delta) X_* + X_*^T \Delta W V_1 W^T \Delta X_* \right] (X_*^T X_*)^{-1}$$
       where $\Delta = \text{diag}(\delta_1, \dots, \delta_{n_1})$ and $V_1 = \text{probit\_res.cov\_params()}$.
    5. Assign `self.coef_cov_ = V2`, `self.coef_stderr_ = np.sqrt(np.maximum(1e-16, np.diag(V2)[:-1]))`, and `self.mills_stderr_ = float(np.sqrt(np.maximum(1e-16, V2[-1, -1])))`.
    6. Ensure `mypy` strict types are fully maintained across all arrays and return types.
  </action>
