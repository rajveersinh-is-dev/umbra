# Plan 01-02: Full-Information Maximum Likelihood (FIML) Heckman Estimation

## Goal
Implement Full-Information Maximum Likelihood (FIML) estimation for `HeckmanSelectionImputer` via joint bivariate normal log-likelihood optimization, with two-step parameter initialization, numerical safeguards, Hessian inversion for asymptotic covariance, and automatic graceful fallback to two-step estimation on non-convergence.

    - Observed Hessian is inverted to obtain asymptotic parameter covariance and standard errors (using the Delta method for $\sigma$ and $\rho$)

  <action>
    Modify `umbra/imputers/heckman_selection.py`:
    1. Update constructor signature to include `method: Literal["two-step", "fiml"] = "two-step"`.
    2. Add custom warning class `HeckmanConvergenceWarning(UserWarning)` if not already defined.
    3. Implement `_fiml_log_likelihood(theta, X_obs, y_obs, W_obs, W_unobs)`:
       - Extract $\beta = \theta[:k]$, $\gamma = \theta[k:k+m]$, $\sigma = \exp(\theta[k+m])$, $\rho = \tanh(\theta[k+m+1])$.
       - For unobserved units ($s_i = 0$): compute $\sum \ln \Phi(-W_{\text{unobs}} \gamma) = \sum \ln(1 - \Phi(W_{\text{unobs}} \gamma))$ using `scipy.special.log_ndtr(-W \gamma)`.
       - For observed units ($s_i = 1$): compute $\sum [-\frac{1}{2}\ln(2\pi) - \ln \sigma - \frac{(y_i - x_i \beta)^2}{2\sigma^2} + \ln \Phi(\frac{w_i \gamma + \frac{\rho}{\sigma}(y_i - x_i \beta)}{\sqrt{1 - \rho^2}})]$.
       - Return negative log-likelihood for minimization.
    4. Implement `_fit_fiml`:
       - Run two-step estimation first to obtain initial guesses $\theta_0 = (\hat{\beta}_{\text{two-step}}, \hat{\gamma}_{\text{probit}}, \ln \hat{\sigma}, \text{atanh}(\hat{\rho}))$.
       - Run `scipy.optimize.minimize` with tolerance $10^{-6}$.
       - If optimization converges and Hessian is positive definite, extract parameters, compute Delta-method standard errors, and assign `self.method_used_ = "fiml"`.
       - If optimization fails to converge, or Hessian inversion fails, issue `HeckmanConvergenceWarning("FIML optimization did not converge or yielded singular Hessian; falling back to two-step estimator.")`, assign two-step estimates with Murphy-Topel standard errors, and set `self.method_used_ = "two-step"`.
  </action>
