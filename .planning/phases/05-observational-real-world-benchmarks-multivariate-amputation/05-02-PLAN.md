# Plan 05-02: Observational Dataset Loaders & Comparative Benchmark Suite

**Goal:** Implement automated dataset loaders (`load_cps_wage`, `load_nhanes_biomarkers`, `load_california_housing`) in `umbra/data/loaders.py`, create the comparative observational benchmark pipeline in `benchmarks/observational_benchmark.py`, and author `tests/test_amputation_and_benchmarks.py`.
**Requirements:** `EVAL-02`, `EVAL-03`

## Tasks

1. **Create `umbra/data/loaders.py` and `umbra/data/__init__.py`**:
   - Locate files in `data/processed/` (`cps_income_observed.csv`, `cps_income_complete.csv`, `nhanes_health_observed.csv`, etc.).
   - Implement `load_cps_wage(split='observed', as_frame=True)`:
     - Returns DataFrame with `annual_income`, `education_years`, `hours_per_week`, `contact_attempts`, etc.
     - Supports `split="observed"`, `split="complete"`, `split="both"`.
     - Provides offline synthetic fallback generator if CSV files are not found.
   - Implement `load_nhanes_biomarkers(split='observed', as_frame=True)`:
     - Returns DataFrame with `fasting_glucose`, `bmi`, `systolic_bp`, `cholesterol`, `phlebotomy_difficulty`.
   - Implement `load_california_housing(split='observed', as_frame=True)`.
   - Re-export loaders in `umbra.data` and `umbra`.

2. **Create `benchmarks/observational_benchmark.py`**:
   - Function `run_observational_benchmark(datasets=None, quick=False, random_state=42) -> pd.DataFrame`:
     - Evaluates 6 methods: Complete Case Analysis, Mean Imputation, Standard MICE, Umbra Auto-Router, Umbra Heckman, Umbra Pattern Mixture.
     - Computes RMSE, MAE, downstream regression slope error, Rubin 95% CI coverage, and runtime.
     - Generates Markdown table and saves `benchmarks/observational_results.md`.

3. **Author Test Suite `tests/test_amputation_and_benchmarks.py`**:
   - Test `ampute_multivariate` pattern allocation, proportion accuracy, MAR/MNAR weights, and odds functions (`RIGHT`, `LEFT`, `MID`, `TAIL`).
   - Test all loaders with splits `'observed'`, `'complete'`, `'both'`, and array output.
   - Test `run_observational_benchmark` smoke run ensuring finite non-NaN metrics.
   - Run full regression test suite (151+ tests) and static type/lint checks.
