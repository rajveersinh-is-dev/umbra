# Plan 05-01: Multivariate Amputation Engine (Schouten et al. 2018)

**Goal:** Implement `ampute_multivariate` and `AmputationResult` in `umbra/benchmark/amputation.py` supporting MAR, MNAR, and MCAR missingness mechanisms with configurable odds probability shifts (`RIGHT`, `LEFT`, `MID`, `TAIL`).
**Requirements:** `EVAL-01`

## Tasks

1. **Create `umbra/benchmark/amputation.py`**:
   - Class `AmputationResult`:
     - `data_amputed: pd.DataFrame`
     - `data_complete: pd.DataFrame`
     - `mask: pd.DataFrame` (True = missing, False = observed)
     - `patterns: np.ndarray` (K x P binary pattern matrix)
     - `weights: np.ndarray` (K x P predictor weights)
     - `mechanisms: List[str]`
     - `odds_types: List[str]`
     - `probabilities: np.ndarray` (per-sample amputation probabilities)
     - `empirical_prop: float`
     - `n_incomplete: int`
   - Function `ampute_multivariate(data, prop=0.3, patterns=None, freq=None, mechanisms='MAR', weights=None, odds_type='RIGHT', std_scores=True, random_state=None) -> AmputationResult`:
     - Validate inputs (data DataFrame or 2D ndarray, numeric, prop in (0, 1)).
     - Construct or validate `patterns` matrix (default: single-variable dropout across variables).
     - Normalize pattern frequencies `freq`.
     - Assign observations to pattern groups.
     - Calculate predictor weights:
       - If MAR: enforce $w_{kj} = 0$ for all variables $j$ with $P_{kj} = 0$.
       - If MNAR: allow non-zero weights for $j$ with $P_{kj} = 0$.
       - If MCAR: weights are zeroed, uniform assignment.
     - Compute standardized sum scores $S_{ik}$.
     - Map $S_{ik}$ to probabilities using odds shift (`RIGHT`, `LEFT`, `MID`, `TAIL`) with calibrated offset $b$ via root finding (`scipy.optimize.brentq` / binary search).
     - Stochastic mask realization: $U_i < P_{ik} \implies \text{NaN}$.
     - Return structured `AmputationResult`.

2. **Re-export**:
   - Re-export `ampute_multivariate` and `AmputationResult` in `umbra/benchmark/__init__.py` and top-level `umbra`.

3. **Verify**:
   - Test MAR zero-weight invariant, MNAR self-masking, odds functions, and empirical proportion accuracy.
